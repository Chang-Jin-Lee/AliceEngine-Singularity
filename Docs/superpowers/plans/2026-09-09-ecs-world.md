# SID-02 ECS World Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans for this implementation.

**Goal:** ALI-02의 World/ComponentRegistry 공개 계약을 실제로 링크하고 실행한다.
**Architecture:** 세대가 있는 슬롯과 타입별 sparse/dense 저장소를 사용한다. 공유 저장소를
소유하는 읽기 가드로 포인터 수명을 지키고, 정렬된 교집합 질의와 명시적 지연 파괴를 제공한다.
**Tech Stack:** C++20, CMake 3.24+, 기존 Foundation/Doc/Schema. 외부 의존성·애셋 없음.
**Spec:** [Runtime 공개 계약](../../ARCHITECTURE.md#runtime-contract), SID-02 완료 기준.

## 파일과 경계

- `Engine/Runtime/ECS/`: 레지스트리, 정렬된 네이티브 풀, World 저장소 구현
- `Engine/CMakeLists.txt`: Alice.Runtime을 정적 라이브러리로 등록
- `Engine/Tests/Runtime_ECS_Tests.cpp`, 테스트 CMake: 실제 호출·수명·진단 회귀 검사
- README, Docs/STATUS, Wiki 생성물, SID-02 백로그: 실행 가능 범위와 검증 결과
- 공개 헤더의 계약은 유지한다. 렌더 추출·규칙 실행·씬 로더는 구현하지 않는다.

## 실행 순서

- [x] 테스트를 먼저 추가하고 기존 선언만으로는 링크 실패함을 확인한다.
  `World::Create`, `AcquireRead`, `SetComponent`, `Query`, `CommitDestructions`를 직접 호출한다.
- [x] 레지스트리 등록/동결/스키마 검증을 구현한다. 중복·잘못된 정렬·누락된 참조를 거부하고
  기존 진단 모음을 유지하며 원본 위치와 힌트를 보존한다.
- [x] 정렬된 연속 풀을 구현한다. 성장/제거 때 move-construct 뒤 원본을 파괴하고,
  decode 실패는 기존 컴포넌트를 바꾸지 않는다.
- [x] World 슬롯·읽기 가드·질의·지연 파괴를 구현한다. 오래된 세대와 다른 World ID를 거부하고
  읽기 중 모든 변경을 막는다. World 객체를 먼저 파괴해도 읽기 가드가 저장소를 유지한다.
- [x] 테스트에서 연속 주소·64바이트 정렬·비자명 타입의 수명, 교집합 결과, 중복 파괴,
  가드 이동, 실패 원자성과 진단 위치를 확인한다.
- [x] 세대 비교와 읽기 잠금 검사를 임시 제거해 테스트가 실패하는지 확인 후 복구한다.
- [x] 공식 verify, 위키 테스트/빌드, 독립 리뷰, GitHub CI를 통과하고 커밋·푸시·PR을 만든다.
