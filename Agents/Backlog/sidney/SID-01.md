## 무엇을

`Doc` 모듈 전체. Value 모델, YAML 부분집합 파서, JSON 파서, 왕복 보장 직렬화기.

## 왜

콘텐츠가 전부 텍스트인 엔진에서 파서는 **가장 중요한 모듈**이다.
그리고 파서의 에러 메시지는 제품 기능이다 — AI 가 그것만 보고 고쳐야 하기 때문이다.
서드파티 YAML 라이브러리로는 그 품질을 낼 수 없어서 직접 썼다.

## 완료 기준

- [x] 맵의 키 순서가 보존된다 (diff 가 읽혀야 한다)
- [x] 정수와 실수가 구분된다 (3 과 3.0 이 왕복 후에도 그대로)
- [x] 모든 값이 소스 위치를 들고 다닌다
- [x] 왕복 테스트 통과: 파싱 → 직렬화 → 재파싱이 같은 값
- [x] 탭 들여쓰기·중복 키·앵커에 명확한 진단과 대안 제시
- [x] `color: #ff8800` 이 주석에 먹히는 사고를 파서가 직접 잡는다
