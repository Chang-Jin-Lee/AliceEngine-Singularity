# SID-03 · Scene 로더

```
상태: 대기
크기: L
선행: SID-02

```

## 무엇을

`scene` 문서를 읽어 World 를 채운다. 컴포넌트 문서 → 컴포넌트 인스턴스.

## 왜

여기가 "텍스트가 게임이 되는" 지점이다. 이게 없으면 지금까지 만든 문서 모델이
검증기에서 멈춘다.

## 완료 기준

- [ ] `alice/scene/1` 문서가 World 를 만든다
- [ ] 액터 계층(children)이 트랜스폼 부모-자식으로 반영된다
- [ ] 알려진 컴포넌트 9종이 전부 로딩된다
- [ ] `preload` 목록이 씬 진입 전에 처리된다
- [ ] 로딩 실패가 구조화 로그로 나가고 씬은 부분적으로라도 뜬다
- [ ] 테스트: FirstLight 샘플이 로딩된다
