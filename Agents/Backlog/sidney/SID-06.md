# SID-06 · 프레임 루프와 고정 시간 스텝

```
상태: 대기
크기: M
선행: SID-02
담당: -
```

## 무엇을

게임 루프. 가변 렌더 프레임 + 고정 물리 스텝.

## 왜

물리와 규칙 평가는 고정 스텝이어야 재현 가능하다. 렌더는 가변이어야 부드럽다.
그 둘을 섞는 방식이 엔진의 성격을 정한다.

델타 타임 클램프를 잊으면 브레이크포인트 한 번에 물리가 폭발한다.
베이스 엔진에서 `presentMs` 가 100ms 에서 포화된 이유가 그 클램프였다.

## 완료 기준

- [ ] 고정 스텝(기본 1/60)으로 물리와 규칙이 돌아간다
- [ ] 렌더는 가변 프레임
- [ ] 델타 타임 클램프가 있고, 클램프가 걸리면 로그가 나간다
- [ ] `Profiler::BeginFrame/EndFrame` 이 루프에 물려 있다
- [ ] 프로젝트 문서의 `budgets` 가 프로파일러에 주입된다
