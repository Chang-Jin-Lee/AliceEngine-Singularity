# SID-04 · 규칙 평가기

```
상태: 대기
크기: L
선행: SID-03
담당: -
```

## 무엇을

`behavior` 문서의 `when/do` 를 매 프레임 평가하고 실행한다.

- 조건식 AST 평가 (파서는 이미 있다: `Engine/Verbs/Expression.h`)
- 동사 디스패치
- `once`, `cooldown` 처리
- 지역 변수 저장소

## 왜

**이것이 언리얼의 블루프린트 VM, 유니티의 스크립트 런타임 자리다.**

핵심 불변식: 같은 프레임의 규칙들을 어떤 순서로 평가해도 결과가 같아야 한다.
그래서 평가는 두 단계로 한다 — 먼저 모든 `when` 을 평가해 발동 목록을 만들고,
그 다음 `do` 들을 실행한다. 중간에 상태가 바뀌어 뒤 규칙의 조건이 달라지면 안 된다.

## 완료 기준

- [ ] 조건식이 평가된다 (식 파서 재사용)
- [ ] 동사가 디스패치된다
- [ ] 규칙 평가 순서가 결과에 영향을 주지 않는다 (테스트로 강제)
- [ ] `once` 와 `cooldown` 이 동작한다
- [ ] 지역 변수가 `var.set`/`var.add` 로 갱신된다
- [ ] `profile.zone` 동사가 실제 프로파일러 존을 만든다
- [ ] `log.write` 동사가 엔진 로그와 같은 스트림으로 나간다
