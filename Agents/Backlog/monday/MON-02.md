# MON-02 · D3D11 백엔드

```
상태: 대기
크기: L
선행: MON-01
담당: -
```

## 무엇을

`IDevice` / `ICommandList` 의 D3D11 구현.

DX11 에는 명령 목록 개념이 약하므로 디퍼드 컨텍스트로 흉내내거나,
단일 즉시 컨텍스트에 직렬화한다. 어느 쪽이든 인터페이스는 같은 얼굴을 유지한다.

## 왜

베이스 엔진이 D3D11 이다. 기존 자산과 셰이더를 가장 빨리 살릴 수 있는 경로이고,
구형 하드웨어와 낮은 사양 노트북에서 유일한 선택지인 경우가 아직 있다.

먼저 붙이는 이유는 "가장 쉬워서"가 아니라 **인터페이스가 정말 백엔드 중립인지 검증**하기
위해서다. 가장 모델이 다른 백엔드가 먼저 통과하면 나머지는 따라온다.

## 완료 기준

- [ ] 디바이스·스왑체인 생성, 리사이즈
- [ ] 버퍼/텍스처/샘플러/셰이더/파이프라인 생성과 파괴
- [ ] 명령 기록과 제출
- [ ] D3D11 타임스탬프 쿼리로 GPU 존 시간을 `Profiler` 에 되먹인다
- [ ] 디버그 레이어를 켰을 때 나오는 경고가 0
- [ ] `ForceLinkD3D11Backend()` 훅 제공
- [ ] 삼각형 하나가 화면에 나온다

베이스 엔진의 `Runtime/Rendering/D3D11` 과 `Runtime/Rendering/Metrics/GpuProfiler` 를
참고할 수 있다. 특히 타임스탬프 쿼리의 disjoint 처리와 다중 프레임 버퍼링은
그대로 가져올 가치가 있다.
