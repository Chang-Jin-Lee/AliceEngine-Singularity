# MON-03 · D3D12 백엔드

```
상태: 대기
크기: L
선행: MON-02
담당: -
```

## 무엇을

D3D12 구현. 바인드리스(SM 6.6 dynamic resources)를 기본 경로로 한다.

## 왜

Windows 의 주력 경로다. D3D11 이 먼저 돌아가고 나면 인터페이스가 검증된 상태이므로
여기서는 성능에 집중할 수 있다.

바인드리스를 기본으로 잡는 이유: 디스크립터 테이블 관리는 백엔드 내부 사정이어야 하는데,
바인딩 모델을 인터페이스에 노출하면 그게 밖으로 샌다.

## 완료 기준

- [ ] D3D12 디바이스, 커맨드 큐, 펜스 동기화
- [ ] 바인드리스 디스크립터 힙
- [ ] D3D12MA 없이 자체 서브할로케이터 (또는 도입 시 Alice 승인)
- [ ] SM 6.6 미지원 어댑터에서 명확한 이유와 함께 거절하고 D3D11 로 떨어진다
- [ ] GPU 타임스탬프
- [ ] MON-02 와 같은 화면이 나온다
