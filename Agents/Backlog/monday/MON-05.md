# MON-05 · 셰이더 컴파일 파이프라인

```
상태: 대기
크기: L
선행: MON-02
담당: -
```

## 무엇을

HLSL 하나를 써서 모든 백엔드로 보낸다.

```
HLSL (SM 6.x)
  ├─ DXC → DXIL      → D3D12
  ├─ FXC → DXBC      → D3D11   (또는 SPIRV-Cross → HLSL SM5)
  ├─ DXC → SPIR-V    → Vulkan
  └─ SPIRV-Cross → MSL → Metal
```

## 왜

셰이더를 백엔드마다 따로 쓰면 그 순간 백엔드 추가 비용이 몇 배가 된다.
소스는 하나여야 한다.

**RHI 인터페이스가 바이트코드만 받는 이유가 이것이다.** 컴파일은 애셋 파이프라인의 일이고,
런타임 인터페이스에 들어오면 안 된다.

## 완료 기준

- [ ] `alice shaders build` 로 전 백엔드 바이트코드 생성
- [ ] 셰이더 캐시 (해시 기반, 변경된 것만 재컴파일)
- [ ] 컴파일 에러가 구조화 진단으로 나온다 (줄·열·힌트)
- [ ] 런타임 핫리로드
- [ ] 리플렉션에서 바인딩 정보 추출
