## 무엇을

패스와 리소스 사용을 선언하면 배리어·상태 전이·리소스 수명을 **자동 계산**한다.

## 왜

이 엔진의 방침 중 하나: **배리어를 콘텐츠 레이어에 노출하지 않는다.**
사람도 AI 도 배리어를 정확히 쓰지 못한다. 틀리면 조용히 깨지거나 드라이버가 죽는다.

RenderGraph 가 있어야 그 약속을 지킬 수 있다.

## 완료 기준

- [ ] 패스 선언 API
- [ ] 리소스 의존 그래프에서 배리어 자동 삽입
- [ ] 트랜지언트 리소스 메모리 앨리어싱
- [ ] 그래프를 JSON 으로 덤프 (AI 가 렌더 파이프라인을 읽을 수 있게)
- [ ] Null 백엔드에서 그래프 정확성 검증
