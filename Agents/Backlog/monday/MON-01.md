## 무엇을

백엔드 중립 그래픽 인터페이스와, 검증기를 겸하는 헤드리스 Null 백엔드.

## 왜

인터페이스를 "가장 낮은 공통분모"가 아니라 **현대적 모델 기준**으로 잡았다.
DX11 을 기준으로 잡고 위로 확장하면 DX12/Vulkan 에서 성능이 안 나온다.
WickedEngine 과 SpartanEngine 이 이 방향을 택했고 실제로 잘 굴러간다.

Null 백엔드는 장난감이 아니다. 핸들 수명, 사용 플래그, 상태 순서를 진짜 백엔드보다
엄격하게 검증한다. GPU 없는 CI 러너에서 렌더 코드 경로를 실제로 실행할 수 있다.

## 완료 기준

- [x] 명령 목록 기반 인터페이스
- [x] 세대 검사가 붙은 핸들
- [x] Null 백엔드가 렌더패스 밖 Draw, 불균형 디버그 그룹, 128바이트 초과 푸시 상수 등을 잡는다
- [x] 종료 시 리소스 누수를 이름과 함께 보고한다
- [x] 백엔드 자동 선택이 실패 이유를 구조화 로그로 남긴다
- [x] 테스트 20개
