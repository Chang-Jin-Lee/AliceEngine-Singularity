# SEE-05 · 진단 품질 회귀 테스트

```
상태: 대기
크기: M
선행: 없음
담당: -
```

## 무엇을

망가진 문서 모음과 기대 진단을 골든 파일로 고정한다.

## 왜

**이 엔진에서 진단 품질은 성능만큼 중요한 지표다.**

힌트가 사라지거나, 위치가 한 줄 어긋나거나, 오타 제안이 엉뚱해지는 회귀는
일반 테스트로는 안 잡힌다. "에러가 나긴 났으니까" 통과해버린다.

골든 파일로 고정하면 진단 문구가 바뀔 때마다 리뷰어가 그 변경을 **의도적으로** 보게 된다.

## 완료 기준

- [ ] `Engine/Tests/Golden/` 에 망가진 문서 30개+
- [ ] 각각의 기대 진단 JSON
- [ ] `--update-golden` 으로 갱신
- [ ] 골든 파일 변경이 PR diff 에 보인다
- [ ] 진단 코드가 사라지면 실패 (안정 식별자 보호)
