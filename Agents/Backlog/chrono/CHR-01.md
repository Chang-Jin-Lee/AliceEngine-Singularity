# CHR-01 · 엔진 내장 AI 대화창

```
상태: 대기
크기: L
선행: 없음
담당: -
```

## 무엇을

엔진 안에서 바로 AI에게 명령한다. PC 에 `claude` 또는 `codex` 가 로그인되어 있으면
별도 설정 없이 동작한다.

```
[엔진 안 대화창]
> 플레이어가 두 번 점프할 수 있게 해줘

AI: behaviors/player_move.behavior.yaml 을 고치겠습니다.
    - maxJumps 를 2로
    - 착지 시 jumpCount 리셋 규칙 추가
    [적용] [문서 보기] [취소]
```

## 왜

요구사항 6. 그리고 이 엔진의 전체 설계가 이 기능을 위해 존재한다 —
콘텐츠가 텍스트이고, 검증이 명령 한 줄이고, 상태를 되읽을 수 있기 때문에
AI 가 엔진 안에서 안전하게 일할 수 있다.

설계는 `Docs/AI_BRIDGE.md` 에 있다. 요점:
- 서브프로세스로 `claude -p --output-format stream-json` 을 띄운다
- AI 에게 주는 도구는 **`alice` CLI 그 자체**다. 별도 API 를 만들지 않는다
- 모든 변경은 적용 전에 diff 로 보여주고 사람이 승인한다
- 승인 후 자동으로 `alice check` 를 돌려 실패하면 되돌린다

## 완료 기준

- [ ] `Engine/Bridge/` 모듈: 프로세스 스폰, 스트림 JSON 파싱, 취소
- [ ] `claude` 와 `codex` 둘 다 지원 (`alice doctor` 가 감지)
- [ ] 대화 기록이 프로젝트에 남아 다음 세션이 이어받는다
- [ ] 변경 전 diff 미리보기와 승인
- [ ] 적용 후 자동 검증, 실패 시 롤백
- [ ] AI 가 엔진 상태(로그·프로파일·씬)를 질의할 수 있다
- [ ] 네트워크 없이도 엔진이 정상 동작한다 (기능이 없을 뿐)
