## 무엇을

Next.js 정적 사이트 + Vercel. 유니티 docs / 언리얼 포럼에 해당하는 것.

**AI 가 크롤링하기 쉽게** 만드는 것이 다른 위키와의 차이다.
- 모든 페이지에 대응하는 `.md` 원문이 같은 URL + `.md` 로 접근된다
- `/llms.txt` 로 전체 구조를 한 파일에 요약 (llmstxt.org 규약)
- `/api/schemas.json`, `/api/verbs.json` 으로 기계용 덤프

## 왜

요구사항 4. 사람이 읽는 위키와 AI 가 읽는 데이터가 **같은 소스**에서 나와야 한다.
따로 만들면 반드시 어긋나고, 어긋난 문서는 없느니만 못하다.
