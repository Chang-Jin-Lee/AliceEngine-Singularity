## 무엇을

**어떤 애셋이든** AI 를 써서 이 엔진에서 쓸 수 있게 만든다.

```
alice adapt path/to/unknown_thing.xyz
  → AI 가 형식을 분석하고
  → 가장 가까운 엔진 문서 타입으로 변환하고
  → 변환 결과를 검증하고
  → 실패하면 무엇이 부족한지 보고한다
```

## 왜

요구사항 5. 언리얼이 C++ 를 UHT 로 돌려 블루프린트를 만들듯,
여기서는 임의의 애셋을 AI 로 돌려 엔진 문서를 만든다.

핵심은 **변환 결과가 곧바로 검증된다**는 점이다. AI 가 뭔가 만들어냈는데
그게 맞는지 모르는 상황이 안 생긴다. `alice check` 가 즉시 판정한다.

## 완료 기준

- [ ] `alice adapt <파일>` 명령
- [ ] 형식 자동 감지 + AI 분석
- [ ] 생성된 문서가 스키마 검증을 통과할 때까지 반복
- [ ] 실패 시 무엇이 부족한지 사람이 읽을 보고서
- [ ] 변환 근거를 `.adapt.yaml` 로 남겨 재현 가능
- [ ] 네트워크/AI 없이도 알려진 형식은 임포터로 처리
