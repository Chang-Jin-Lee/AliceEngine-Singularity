# CHR-05 · 애셋 임포터 프레임워크

```
상태: 대기
크기: L
선행: ALI-03
담당: -
```

## 무엇을

외부 파일(glTF, PNG, WAV 등)을 엔진이 쓸 수 있는 형태로 들여온다.

- 임포터 등록 인터페이스
- 해시 기반 캐시 (원본이 안 바뀌면 재임포트 안 함)
- 임포트 설정을 **문서로** 남긴다 (`.import.yaml`)

## 왜

유니티의 `.meta` 와 같은 개념이지만, 사람과 AI 가 읽고 고칠 수 있는 텍스트여야 한다.
유니티 `.meta` 는 GUID 와 숫자 나열이라 사람이 못 읽는다.

Piccolo 는 애셋을 JSON 으로 저장하지만, 내용이 인덱스 배열이라
사람도 AI 도 의미를 알 수 없다. **JSON 이라고 다 AI 친화가 아니다.**
형식이 아니라 **모양**이 중요하다.

## 완료 기준

- [ ] 임포터 등록 인터페이스
- [ ] glTF / PNG / WAV 임포터
- [ ] 해시 기반 증분 임포트
- [ ] `.import.yaml` 설정 문서 (스키마로 검증됨)
- [ ] 임포트 실패가 구조화 진단으로
- [ ] `alice import` 명령
