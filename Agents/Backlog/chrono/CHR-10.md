# CHR-10 · 현재 기능 안내와 로컬 위키 실행

```
상태: 진행중
크기: M
선행: 없음
담당: Codex (Chrono)
```

## 무엇을

README와 위키에 Phase 0에서 실제 실행되는 기능을 안내하고, 정적 빌드한 위키를
로컬 브라우저에서 볼 수 있게 한다. 기존 사이트와 생성 스크립트를 사용한다.

## 왜

문서 검증 CLI와 게임 런타임을 구분해야 사용자가 현재 엔진을 직접 시험할 수 있다.
`npm start`는 정적 내보내기 설정과 충돌하고, `Wiki/lib/content.js`는 전역 `lib/`
무시 규칙으로 저장소에서 빠져 있다. 다른 컴퓨터에서도 같은 위키가 빌드되어야 한다.

## 완료 기준

- [x] README·위키 첫 화면·시작 가이드가 CLI와 런타임의 현재 상태를 구분한다
- [x] 필요한 위키 소스가 Git 추적 대상이다
- [x] 엔진이 없는 환경에서도 저장된 API 데이터로 전체 레퍼런스를 재생성한다
- [x] 정적 빌드와 로컬 미리보기, HTML·마크다운·JSON 접근을 검증한다
- [x] 데스크톱과 모바일 화면을 확인한다
- [x] 실제 CLI 및 Windows 빌드 결과와 실행 방법을 기록한다

## 작업 기록 · 2026-09-07

로컬 구현·검증을 완료했다. 작업 브랜치 `chrono/CHR-10-local-wiki`에 보관하며,
PR을 열고 병합하는 단계는 남아 있으므로 상태를 `진행중`으로 유지한다.

- `Scripts/verify.ps1`: 경고 0 빌드와 테스트 137개를 포함한 6단계 통과
- `npm test`: 엔진 없는 재생성, 정적 서버·리다이렉트·404·경로 제한 확인
- `npm run build`: 정적 내보내기 성공
- 브라우저: 문서 63개, 관련 URL 133개, 데스크톱 1440×1000 / 모바일 390×844 확인
- 독립 코드 리뷰: 차단 사항 없음. 리다이렉트의 쿼리 보존 제안은 재현 테스트 후 수정

별도 서버 패키지를 추가하는 대신 Node 표준 라이브러리로 로컬 미리보기를 제공했다.
새 의존성 없이 `npm start`가 정적 내보내기와 맞게 동작하지만, 이 서버는 로컬 확인 용도다.
공개 호스팅은 기존 Vercel 설정과 `out/` 산출물을 사용한다.
