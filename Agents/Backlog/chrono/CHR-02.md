## 무엇을

콘텐츠 타입 19종 정의, 검증기, JSON Schema 생성.

## 왜

스키마가 이 엔진에서 하는 일은 UHT 가 언리얼에서 하는 일과 같지만 방향이 반대다.
UHT 는 코드에서 메타데이터를 뽑아 에디터로 보낸다.
여기서는 스키마 하나에서 **검증 + 자동완성 + JSON Schema + 위키**가 전부 파생된다.

## 완료 기준

- [x] 19개 콘텐츠 타입 등록
- [x] 오타에 편집 거리 기반 제안
- [x] 첫 에러에서 멈추지 않고 전부 보고
- [x] alias 로 필드 개명 마이그레이션 안내
- [x] JSON Schema draft 2020-12 생성
- [x] 모든 스키마에 설명과 필드 문서가 있음을 테스트가 강제
