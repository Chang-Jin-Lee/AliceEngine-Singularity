## 무엇을

스키마와 동사에서 위키 페이지를 **생성**한다. 손으로 쓰지 않는다.

```
alice wiki generate --out Wiki/content/reference/
```

## 왜

레퍼런스 문서를 손으로 쓰면 반드시 코드와 어긋난다.
스키마·동사가 이미 설명·예시·흔한 실수를 들고 있으므로, 그걸 그대로 페이지로 만든다.

**손으로 쓰는 것은 개념 설명과 튜토리얼뿐이다.**

## 완료 기준

- [ ] `alice wiki generate` 명령
- [ ] 스키마 19종 → 레퍼런스 페이지
- [ ] 동사 32개 → 레퍼런스 페이지
- [ ] 진단 코드 → 설명 페이지 (`alice explain` 과 같은 표)
- [ ] CI 가 생성물이 최신인지 검사
- [ ] 생성 페이지와 수기 페이지가 명확히 구분됨
