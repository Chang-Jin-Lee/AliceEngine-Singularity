# SID-07 검증 기록

2026-09-17, Windows, Intel Core i9-14900HX(24코어/32스레드), MSVC 19.51.36248.0, Windows SDK 10.0.26100.0, RelWithDebInfo /O2.

## 구현 및 회귀 검증

- 기존 기준: 173개 테스트 통과. 최종 구현: 191개 통과, 0 실패.
- 최초 통합 테스트 3개는 character2d 미등록·미실행 때문에 실패했다. 코어 스텁에서는 얇은 바닥 관통, 벽/천장, 겹침/진단 테스트가 실패했다. 구현 후 통과했다.
- 별도 리뷰가 발견한 모서리 접선 오충돌은 `(0,0)→(2,2)`가 장애물 모서리를 스치며 x=1에서 막히는 테스트로 재현했다. entry==exit를 충돌에서 제외한 후 통과했다.
- 매우 작은 지형 collider 오류가 player를 가리키는 회귀 테스트를 추가하고 실패를 확인했다. 개별 지형의 소스 위치로 CheckBox를 호출해 수정했다.
- 세션 재사용 시 바인딩·속도·누적 시간이 남고 로드 실패 때 상태가 덮이는 문제를 재현했다. 임시 세션에 로드한 후 성공할 때만 교체하도록 수정했다.
- player 아닌 곳의 character2d가 일반 미리보기로 잘못 들어가는 경우를 재현하고 위치·힌트 있는 진단으로 수정했다.
- 실제 중력 계산을 의도적으로 제거했을 때 LandsJumpsAndPreservesSource가 착지/점프 두 단언에서 실패했다. 즉시 원복·재빌드하고 전체 191개 통과를 확인했다.
- 별도 리뷰의 최종 재검토에서 추가 수정 필요 사항 없음. 최종 전체 검증·문서 완성을 조건으로 코드 리뷰 통과.

핵심 검증: 낙하/착지, 공중 점프 거부, 누름 유지 시 재점프 거부, 물리 스텝 없는 프레임의 점프 보존, 프레임 분할 일치, 긴 프레임 제한, 얇은 바닥 고속 이동, 벽/천장, 모서리/접선, 발판 이탈, 초기 겹침/탈출 불가, NaN/Inf/범위 오류, 잘못된 지형의 소스 위치, 원자적 로드, 대체 제공자, 공간 검색/전수 검색 동등성, 원본 씬 복구.

## 성능 재현

Alice.PhysicsBench는 지형 100/1,000/10,000개, 독립 캐릭터 쿼리 1/100개, 간격 8/1의 희소/밀집 격자를 조회한다. 난수 없이 결정적인 배치다. 각 쿼리는 같은 시작 위치에서 `[0.03,-0.4]` 이동을 반복하며 실제 고정 스텝 루프·ECS·창 렌더링 비용은 포함하지 않는다. JSON의 fixed_dt는 참고 시간 단위이며 중력을 적분하는 벤치마크가 아니다.

준비 20회, 측정 100회, 프로파일러 off. 구축 시간은 별도 build_us. candidates/exact_tests는 측정 100회 전체의 합이다. 같은 충돌 판정에 indexed=true/false만 다르게 적용하며 타이밍 밖에서 결과 동등성을 확인한다. CI 성능 기준은 벽시계 시간이 아니라 결과 동등성과 검사 횟수 감소다.

## 절차 기록

작업 선점: b51632a, Sidney, SID-07. 사용자 승인으로 스키마·에디터·테스트 연결 포함. 기존 조사 문서는 Testing 내부에서 업데이트했다. 새 Runtime 공개 헤더는 독립 컴파일 계약 검사에 포함했다. 기존 다른 모듈 공개 헤더는 변경하지 않았다.

제한 환경에서는 빌드 정지·ConPTY 실패 사례가 있어 제한 밖에서 검증했다. Git safe.directory는 명령/프로세스 단위로 적용하며 전역 설정은 바꾸지 않았다. 위키는 기존 package-lock.json대로 npm ci 후 생성·테스트했으며 엔진 외부 의존성은 추가하지 않았다.

개발 원시 출력은 로컬 Testing/results에 두고 커밋에서 제외한다. 공유 성능 결과는 Testing/Measurements에 보관한다. 전체 verify 및 원격 CI/PR 결과는 최종 통합 단계에서 기록한다.

최종 로컬 검증: Scripts/verify.ps1 -BuildDir Testing/build 전체 6개 단계 통과. CTest 활성 5개(191개 단위 테스트를 실행하는 러너, 콘텐츠/정규화, 실제 창 2개) 통과. 비활성 JSON CTest와 별개로 Alice.Tests --json을 직접 실행해 191/0 확인. npm test 2개 및 npm run build 통과.

PR #7 첫 원격 실행에서 GCC/Clang은 로그 매크로를 감싼 중괄호 없는 if를 dangling-else 경고로 거부했다. 해당 if에 중괄호를 추가했다. MSVC 로컬 검증만으로 이식성 검증을 대신할 수 없음을 확인했다. 위키·개발 규칙은 첫 원격 실행에서도 통과했다.
